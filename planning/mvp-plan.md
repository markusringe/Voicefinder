# MVP Plan

## Goal
Build a native Swift voice assistant with on-device STT, lightweight local reply generation, and local TTS.

## Scope
- One conversation screen
- Speech input
- Simple response logic
- Spoken output

## Phases
1. Core protocols
2. Apple STT
3. Conversation orchestrator
4. Apple TTS
5. Local reply engine
6. Kokoro integration
7. Tests and device validation
